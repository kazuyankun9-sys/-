# 競業・本業の情報チェックリスト（出品前に必ず確認）

ここは代わりに判断できない部分です。就業規則を確認したうえで、**全部「はい」になってから**出品してください。

## 1. 就業規則
- [ ] 副業が禁止されていない（許可制なら申請済み）
- [ ] 「競業避止」の条文を読み、Web診断・改善提案が該当しないか確認した
- [ ] 判断がつかない場合、人事に「ナレーション（声の仕事）」と「Web診断」を分けて確認した
  - ナレーションは本業と無関係なので、通りやすい。**先にナレーションだけ出品する**のが安全

## 2. 出品文・プロフィールに書かないこと
- [ ] 勤め先の社名、業界、職種名（「OA機器」「Web営業」など）、所在地
- [ ] 「現役営業マンが」「◯社のサイトを提案してきた」などの経歴
- [ ] 勤め先のロゴ、資料、提案書、価格表、事例のスクリーンショット
- [ ] 本名・顔写真（身バレ防止。ニックネームとイラストで十分）

## 3. 受けない仕事
- [ ] サイト制作・改修・保守、ドメイン・サーバー、OA機器、複合機、回線、広告運用
- [ ] 勤め先の顧客・見込み客・取引先からの依頼（気づいた時点で丁寧にお断り）
- [ ] 勤め先の営業エリアの法人からの依頼（不安なら「個人事業主・小規模店舗のみ」に限定）
- [ ] 診断後に「制作を頼みたい」と言われた場合 → 「制作はおこなっていません」と答える。勤め先にも自分にも誘導しない

## 4. 作業のルール
- [ ] 副業は会社のパソコン・スマホ・アカウントを使わない
- [ ] 勤務時間中にメッセージ対応をしない（ココナラのプロフィールに「返信は平日19時以降」と書く）
- [ ] 会社で使っている有料ツール・社内テンプレートを使わない
- [ ] 自作の「サイトカルテAI」は、個人のパソコンと個人のアカウントで動かす

## 5. 税金
- [ ] 副業の所得（売上−経費）が年20万円を超えたら確定申告
- [ ] 住民税の「普通徴収（自分で納付）」を選ぶと、会社に副業が伝わりにくい（自治体による）
