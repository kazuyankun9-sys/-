## 1日1.5時間の回し方

### 最初の2週間（出品まで）

| 日 | やること（各90分） |
|---|---|
| 1日目 | 就業規則を確認（04）。ココナラに登録、プロフィール作成（ニックネーム＋イラスト） |
| 2日目 | サンプル原稿3本を声に出して練習、読めない言葉の確認 |
| 3日目 | サンプル1・2を録音・編集 |
| 4日目 | サンプル3を録音・編集。3本を聞き直して、気になる箇所を録り直す |
| 5日目 | サムネ画像作成（Canva）、ナレーションの出品文を登録 → **出品** |
| 6〜7日目 | 休み、または予備日 |
| 8日目 | 診断レポートのテンプレートをGoogleドキュメントで作成 |
| 9〜10日目 | 自分の知人・家族のお店のサイトで練習診断（1件） |
| 11日目 | 練習分のレポートを「サンプルレポート」として整える（店名・URLは伏せる） |
| 12日目 | 診断の出品文・サムネを登録 → **出品**（04が全部「はい」の場合のみ） |

### 出品後の毎日（90分）

| 時間 | やること |
|---|---|
| 10分 | メッセージ・見積もり依頼への返信（返信の早さは検索順位に影響する） |
| 60分 | 受注した作業（ナレーション1本、または診断の半分） |
| 20分 | 受注がない日：「公開依頼」（仕事の募集）を見て提案を2〜3件送る／サンプルを1本追加 |

### 目標の目安

| 時期 | 目標 |
|---|---|
| 出品から1か月 | 評価3件（最初は値下げ価格でよい） |
| 2〜3か月 | ナレーション月4〜6件＋診断月2〜4件 → 月3〜6万円 |
| 評価10件以降 | ナレーションを5,000円、診断のプレミアムを主力にして単価アップ |
